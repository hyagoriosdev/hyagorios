# Under Improvements Landing Page

"Under Improvements" web page

## Features

- **WebGL Shader Background**: An interactive and mesmerizing animated background built with `three.js`.
- **Liquid Glass Buttons**: Premium UI components with a glassmorphism effect.
- **Fully Responsive**: Adapts seamlessly to different screen sizes.
- **Dark Mode**: Optimized for a visually striking dark theme.
- **Minimalist Design**: Clean typography focusing on the core message.

## Technologies Used

- **Angular**: Frontend framework.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **Three.js**: Lightweight 3D library for the WebGL background animation.
